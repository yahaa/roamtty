Terminal gestures and anchored file menus — 2026-10-01

Changes:
- File-row actions use a DropdownMenu anchored to the row's ellipsis, matching host cards. Download, Save as, Rename and Delete remain available; destructive confirmation is retained.
- Holding the live command line displays a magnifier and moves the remote cursor with unmodified left/right keys. Supports soft wraps and wide characters. Release, cancel, resizing, detaching, loss of window focus and screen changes dismiss the lens. Other output retains selection/copy.
- Double-tapping a detected path in live or captured output offers Copy path and Download. Handles quoted/escaped spaces, Unicode, soft wraps, and file:line:column suffixes. Downloads share the existing destination flow. ~/ resolves through the SFTP home; other relative paths require an absolute or ~/ path because shell cwd is unknown.
