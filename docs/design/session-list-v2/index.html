会话列表 · 新设计预览

参考你给的那张 Codex 浮窗：一行就是一次对话，把“你问了什么 / 它答了什么 / 现在在干嘛”直接摆出来，按状态分组，最需要你的放最上面。

和现在的区别

  • 按状态分组：待确认 → 运行中 → 已完成 → 终端，顶部筛选条带计数（可点）。
  • 三行内容：标题行（Agent 徽标 · 目录 · 任务 · 时长）、你: 最后一次提问、Agent 最后回复或正在跑的命令。
  • 就地操作：等待确认的直接给「允许 / 查看」；已完成的给「追问」，点开是行内输入框，不用进终端。
  • 更密：去掉大卡片和 ⋮，改成分组圆角容器 + 细分隔线，一屏能放 7–8 个会话（现在约 4 个）。关闭放到长按/左滑。
  • 状态点留在图标右下角；运行中会呼吸，待确认的行左侧有琥珀色竖条。

数据对接

  • 标题、目录、时长、tmux/mosh 标签、状态：现有 AgentStatus 已有。
  • 你: 行 ≈ 现有 task。
  • Agent 最后回复摘要：需要 hook 额外上报一段 last_reply（Stop hook 里取最后一条 assistant 消息前 200 字）。
  • 行内「追问 / 允许」：往 tmux pane send-keys。
