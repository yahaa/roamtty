C · 终端工具栏里打开远程桌面

现在：“打开桌面”藏在工具栏 ⚙ 设置菜单的第一项。三种放法如下，只有装了桌面插件的主机才显示（虚线框 = 新加的部分）。

  • 竖向工具栏多一格（横屏双列不受影响）

D · 点小精灵出来的工具栏自动隐藏

现在：点小精灵弹出工具栏后，它会一直留着，必须点 ✕ 或菜单里的“隐藏操作栏”。“固定操作栏”的情况不变，不会自动隐藏。下面的动画演示每种方式的消失过程（循环播放）。

D1闲置 5 秒自动收起
12:343G ▮
desktop@dev-ubuntu:~$
✕ 外面那圈是倒计时：5 秒没碰工具栏就收回成小精灵。碰一下任何按钮，倒计时重来；打开子菜单时暂停。
  • 不用管它，自己会走
  • 倒计时圈让人知道它要消失了
  • 慢慢看菜单时可能被收走（子菜单打开时会暂停）
D2用完即走推荐
12:343G ▮
desktop@dev-ubuntu:~$
收起的时机：
点了一个功能→点终端区域→弹出键盘→8 秒没碰
任一条发生就收回成小精灵。最下面的 📌 = 固定，固定后不再自动收起。
  • 符合直觉：点完功能、或者回去打字，它就让开
  • 8 秒兜底时间比较长，慢慢选不会被打断
  • “固定”从 ⚙ 菜单提到工具栏上，一点即可
  • 要连续用两个功能（先上传再下载）得点两次小精灵
D3收成边缘细条
12:343G ▮
desktop@dev-ubuntu:~$
5 秒闲置后不是变回小精灵，而是缩成右边一根细条（像 iOS 的侧边把手）。从右边缘往左一划，工具栏立刻回来；小精灵依然负责第一次打开。
  • 再次打开很快，不用再找小精灵
  • 屏幕右边一直多一根细条
  • 右边缘左滑和系统“返回”手势冲突，要避开系统手势区
怎么选： 回复例如 C1 + D2（我推荐的组合）。C1 和 C2 可以同时要。
