✕ 关闭

右上角 26dp 小圆按钮（触控区 40dp）。点后信息框消失，等同在「操作 → 显示网络状态」里关掉，设置会记住；底部提示「已隐藏，可在 操作 中重新打开」。

长按拖动

长按 400ms 进入拖动态：边框高亮 + 放大 4% + 轻震。之后跟手移动，限制在画面区域内（不压右侧按钮栏）。短按 / 普通滑动不触发，不影响远程桌面的点击与滚动。

位置记忆

松手后保存位置（按画面比例存，横竖屏切换都不会跑出屏幕）。「操作」面板加一个「恢复默认位置」入口。
