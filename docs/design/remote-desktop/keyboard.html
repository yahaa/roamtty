远程桌面键盘 · 设计稿（已确认：快捷键栏默认隐藏）

和终端一样：点底栏「键盘」直接弹出手机系统输入法，不再有「输入法 / 电脑键盘」两页和输入框。快捷键栏默认隐藏：输入法右上角只有一个小的「快捷键 ▴」按钮，点开才显示 Esc、Tab、Ctrl、Alt、Win(Mac 为 ⌃/⌥/⌘)、方向键、⋯ 更多；点栏尾 ▾ 再收起（本次连接内记住）。下面 A/B/C 三张是展开后的样子。

  • 拼音组字时，组字内容以小气泡显示在远程光标附近，上屏后直接发到电脑。
  • 修饰键：点一下只作用于下一个键（描边），长按锁定（实心），配合输入法字母即可发 Ctrl+C 等组合键。
  • 「⋯」把输入法换成按键面板（F 键、Home/End/PgUp/PgDn、Del、常用组合），点 ABC 回到输入法。
  • 画面自动上移，保证光标附近可见；再点「键盘」或返回键收起。
