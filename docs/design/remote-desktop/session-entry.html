会话列表上的远程桌面入口 · 5 个思路

基于当前会话列表（会话/主机标签、筛选胶囊、按 agent 状态分组的卡片）。只有"有图形桌面"的主机才显示入口；首次点击仍走"安装插件 → 授权 → 画面"的流程。橙色描边标出每个方案改动的位置。页面底部有对比和推荐。

推荐：A（顶部桌面条）+ C（卡片按钮），E 作为兜底。

• 桌面条只在至少有一台主机能开桌面时出现，放这些主机的桌面；已连接的显示实时缩略图和延迟，未连接的显示主机图标和"点按连接"。点一下就进入。桌面不进入下方 agent 分组，避免"等待/进行中/已完成"里混入没有 agent 状态的东西。

• 卡片底行的桌面图标让"agent 让我去看一眼、点一下"一步到位；agent 状态为"等待确认"时按钮高亮。

• 新建会话菜单加"远程桌面"，用于桌面条被收起，或想连接还没探测过的主机时。
