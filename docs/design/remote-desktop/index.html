流程总览

主入口是会话卡片右下角的桌面按钮；还没有会话的主机，从主机页「桌面」按钮进入。两个入口后面的流程完全相同。每一行是一条路径，从左往右走。

主入口：会话卡片右下角的桌面按钮

只要会话所在的主机能开桌面，这张会话卡片底行最右边就多一个小的桌面按钮（与"追问"同款圆角按钮）。原则：点一下就打开；第一次用时就地引导安装，装完自动打开，不需要回到列表再点。同一台主机的多个会话都显示，点哪个都打开这台主机的同一个桌面。

首次连接：安装插件 → 授权 → 画面

从卡片按钮或任何次要入口进入，整个流程只有一次"安装并打开"，装完自动打开；macOS 多一步本机授权；没有图形桌面的主机在安装前就会被拦下。01 是次要入口（主机页）。

桌面页（横屏全屏）· 参考 UU 远程

结构照 UU 远程手机端：远程画面居中，右侧黑边里一条竖栏放 4 个带文字的入口：操作、键盘、显示桌面、所有窗口。不常用的功能都收进"操作"面板。左侧黑边只在左下角显示网络状态。光标在手机本地绘制。

键盘与网络状态

键盘面板照 UU：底部全宽，分"输入法"和"电脑键盘"两页；画面上移，只露出光标附近。网络差时先告诉用户发生了什么、已经降到什么档位。

竖屏

照 UU：画面在上方按宽度铺满，底部一排标签栏放和横屏竖栏相同的 4 个入口，面板从底部弹出。"鼠标指针"方式下，画面下方的黑色区域也能当触控板用。

1. 桌面按钮的显示规则

项规则
出现在哪会话卡片底行最右边，"追问"按钮右侧；没有"追问"的普通终端会话，按钮同样在最右边。会话所在主机"能开桌面"时才显示
哪些主机算"能开桌面"① 探测结果缓存为"有桌面"；② 还没探测过但系统是 macOS / Windows（主机已记录系统类型）。Linux 主机在探测确认有桌面后才显示按钮。探测为"无桌面"的主机不显示
何时探测只读、无副作用：该主机的会话连上时顺带执行（复用已有连接）、打开主机页时。结果缓存 7 天；插件已安装的主机每次连接都会刷新
不显示的情况主机离线、会话未连接（断开或失败）、主机没有桌面
同一主机多个会话每张卡片都显示按钮，打开的是这台主机同一个桌面；状态在这些卡片上同步
尺寸看得见的按钮 34×30 dp，圆角 15，图标 17 dp；可点区域 44×44 dp；角标 8 dp；与"追问"间距 7 dp
无障碍朗读为"打开 MacBook 的桌面"，带状态："已连接""需要授权"等

2. 操作与导航

操作结果
点按桌面按钮能直接打开就直接打开：进入该会话所在主机的桌面，不打开会话本身（点卡片其他位置仍是打开会话）。已连接：直接进入，≤ 1 s。已装插件：按钮转圈（超过 300 ms 才显示）→ 桌面页。没装插件：弹出安装卡片，装完自动进入桌面页。缺授权 / 无人登录：直接打开对应的引导，满足后自动进入。按钮没有长按操作
退出桌面页操作 › 退出，或系统返回手势：回到进入前的页面。桌面连接在后台保持 10 分钟（画面停止传输），按钮显示"已连接"；10 分钟后自动断开，插件端会话保留
次要入口主机页「桌面」按钮（还没有会话的主机就从这里打开）、终端页工具栏的桌面图标：行为与点按卡片上的桌面按钮完全相同
通知栏现有常驻通知里，已连接的桌面增加一行"MacBook 桌面 · 已连接"，点按回到桌面页
同一主机重复打开每台主机最多一个桌面，重复点按回到已有的那个

3. 连接状态

状态卡片上的按钮桌面页离开条件
未连接默认底色 + 桌面图标—点按 → 连接中
连接中图标换成转圈连接中页（三步进度）首帧到达 → 已连接；失败 → 未连接并提示原因
需要安装同"未连接"安装卡片 → 进度装好 → 连接中；取消 → 未连接
需要操作右上角黄色角标授权页或"请在本机登录"说明条件满足（每秒检测）→ 自动连接
已连接橙色底 + 右上角绿色角标画面返回 → 后台保持；断开 → 未连接
网络较差橙色底 + 黄色角标"网络较差 · 已降到 720p30"角标连续 5 s 正常后恢复
恢复中橙色底 + 转圈保留上一帧；超过 2 s 显示恢复卡片UDP ≤ 1 s、SSH ≤ 3 s 内恢复；30 s 未恢复 → 未连接并提示
后台保持同"已连接"—10 分钟 → 未连接
离线不显示—主机恢复在线（沿用主机在线检测）

4. 桌面页操作

手势 / 入口屏幕触控（默认，与 UU 一致）鼠标指针
单指轻点在手指位置左键单击在光标位置左键单击
单指滑动放大时拖动画面；未放大时无操作相对移动光标（画面外的黑色区域也可以）
单指长按右键右键
轻点后立即按住拖动按住左键拖拽 / 框选
双指滑动滚轮（像素级平滑滚动）
双指捏合放大 / 缩小画面（手机本地完成，不改远端分辨率）；放大后光标靠近边缘时画面自动跟随
虚拟鼠标操作面板里打开；悬浮鼠标可拖动，含左键、右键、滚轮；关闭后记住位置
竖栏：显示桌面macOS 发"显示桌面"，Windows 发 Win+D，Linux 发 Super+D
竖栏：所有窗口macOS 发"调度中心"，Windows 发 Win+Tab，Linux 发 Super
退出操作 › 退出，或系统返回手势（只在两侧黑边处触发；画面区域设为手势排除区）
外接鼠标 / 键盘鼠标走指针捕获（相对移动），键盘按键直通；被 Android 截获的组合键用电脑键盘面板补发

5. 时间与阈值

项值
按钮转圈出现点按后 300 ms 仍未进入桌面页才转圈，避免闪一下
首帧目标已连接 ≤ 1 s；新连接 ≤ 2 s；首次安装（含下载）≤ 15 s
授权检测每 1 s 一次，离开授权页即停止
"网络较差"角标画面停顿 > 300 ms 出现；连续 5 s 正常后消失
恢复卡片中断 > 2 s 出现；30 s 未恢复则断开并提示
后台保持离开桌面页后保持 10 分钟（可在设置中改为 5 / 10 / 30 分钟）

6. 异常与文案

情况表现与文案
主机离线按钮不显示；从主机页点按时提示："MacBook 离线，无法打开桌面"
SSH 认证失败 / 指纹变化复用现有连接弹窗（密码、指纹确认），确认后继续
没有图形桌面说明卡片："这台主机没有图形桌面"；不安装任何东西，该主机的会话卡片不再显示桌面按钮
Windows / macOS 无人登录按钮黄色角标；点按显示"请先在这台电脑上登录桌面"
插件下载失败主机下载失败自动改为手机下载；都失败时："下载桌面插件失败"，按钮"重试"
macOS 授权过期（每月提示）按钮黄色角标；点按打开授权页，文案"macOS 要求每月确认一次屏幕录制权限，请在 Mac 上点「允许」"
远程锁屏画面照常显示锁屏；顶部提示"远程电脑已锁屏，请在本机解锁"（首期不支持远程输入密码解锁）
插件版本过旧连接前静默升级，不提示；升级失败按"下载失败"处理
